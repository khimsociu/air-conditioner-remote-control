# air-conditioner-remote-control
❄️ Smart Air Conditioner Controller (ESP32-S3)An IoT universal air conditioner (AC) remote control project built on PlatformIO for the ESP32-S3 Super Mini microcontroller. The system supports receiving and transmitting Infrared (IR) signals for various popular AC brands, featuring an intuitive OLED display interface and remote control via an embedded Web Server and MQTT.✨ Key FeaturesWide AC Brand Compatibility: Powered by the IRremoteESP8266 library to decode and transmit IR signals for most major AC manufacturers (Daikin, Panasonic, LG, Mitsubishi, Casper, Gree, Toshiba, Samsung, Carrier, etc.).Web-Based Control (Web Server): Built-in local Web Server allowing users to toggle power, adjust temperature, switch modes (Cool, Dry, Fan, Auto), and control fan speed directly from a smartphone or PC browser.IoT Integration via MQTT: Supports the MQTT protocol (PubSubClient) for seamless integration with smart home platforms (Home Assistant, Node-RED, or custom mobile apps).Visual Status Display: Utilizes the U8g2 graphics library to display operating states, target temperature, and Wi-Fi/MQTT connection status on an OLED/LCD screen.Persistent Storage: Uses ESP32 non-volatile Flash memory (Preferences) to save Wi-Fi credentials, MQTT configurations, and the last known AC state across power cycles.GPS & Real-Time Expansion: Includes TinyGPSPlus library support for time synchronization or location-based automation (Geofencing).🛠️ Hardware RequirementsMicrocontroller: ESP32-S3 Super MiniIR Transmitter Module: 940nm Infrared LED (paired with a Transistor driver circuit such as 2N2222/S8050 for extended transmission range).IR Receiver Module: 38kHz Infrared Receiver (VS1838B / TSOP4838) (used for learning commands from original remotes).Display: I2C OLED Display (SSD1306 / SH1106).Expansion Module (Optional): UART GPS Module (NEO-6M / NEO-8M).🔌 Pinout ConfigurationNote: Please verify and update these GPIO pin
